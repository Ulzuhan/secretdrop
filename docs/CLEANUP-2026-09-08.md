# SecretDrop: retirada del backend Node — 2026-09-08

## Resultado

El árbol mantenido contiene un solo backend (Go) y una sola interfaz (React/Vite en src/). Esta entrega retira el legado del repositorio; no confirma el cierre de la observación de producción ni despliega. El commit/push se ha autorizado expresamente: el push a main activa la publicación habitual de la imagen de rama, no una nueva release.

## Cambios

- Retirados src/app, el backend TypeScript, proxy de Next, next.config.ts, Dockerfile.node y el postbuild standalone.
- Consolidada la interfaz Go que estaba en web/ dentro de src/; eliminados duplicados y el shim de navegación. Los enlaces son anclas normales, sin prefetch.
- Conservado byte a byte src/lib/crypto.ts: SHA-256 e1a09ed18039605efefe1c36b21fbb284b94fc31912139b2b2cd7af6cd40f945. El cifrado sigue exclusivamente en el navegador.
- Dependencias y lockfile sin Next ni eslint-config-next. Node/npm quedan para construir React y ejecutar herramientas, nunca en el runtime.
- Comandos de desarrollo, build y pruebas alineados con Go; npm run dev usa loopback, almacén local y una clave efímera si no se exporta una.
- CI conserva las suites HTTP, back-channel, reinicio, navegador contra binario e imagen y compatibilidad con la imagen publicada. Sin duplicar las mismas suites contra un backend Node mantenido localmente.
- Regresiones unitarias de identificadores, límites numéricos, recuperación tras error de almacenamiento y discovery OIDC trasladadas a Go. Se mantiene la cobertura de consumo concurrente.
- README reescrito; CONTRIBUTING, AGENTS, reglas de edición/ignorados, configuración de ejemplo, DEPLOYMENT, CONTRATOS y changelog actualizados.

## Validación local

- Lint, typecheck, go vet y go test -race: correctos.
- 10 pruebas unitarias de frontend/cifrado.
- HTTP: auth 34, secretos 53, contratos 23, interfaz 37; 147 correctas.
- Back-channel firmado y reinicio con 2000 registros propios, ajenos y heredados: correctos.
- Recorrido HTTPS en Chromium contra binario y contra imagen: crear, compartir, descifrar, no repetir consumo, clave ausente, logout, estilos, logo, metadatos y portapapeles denegado.
- Compatibilidad imagen Node → Go → imagen Node: 22 comprobaciones correctas.
- Construcción desde una copia limpia sin node_modules, assets generados ni cachés: correcta, con lint, typecheck, unitarias y race.
- Imagen local: runtime sin Node/npm, UID 10001 y healthcheck correcto con raíz de sólo lectura, cap_drop ALL, no-new-privileges, pids 256 y 512 MiB de límite. Almacén sintético en tmpfs, sin datos reales.
- npm audit: cero vulnerabilidades notificadas.
- Portada inspeccionada visualmente: contenido y estilos presentes, sin errores del navegador.

Los puertos habituales 9999 y 3992 estaban ocupados. Las suites HTTP se ejecutaron con PORT=13992 y PUERTO_IDP=13999 sin detener ni modificar esos procesos. No hubo campaña de carga ni peticiones a producción.

Estos resultados corresponden a la validación local. CI y publicación remotos deben comprobarse para el SHA exacto del commit en GitHub Actions; no se deducen del resultado local.
